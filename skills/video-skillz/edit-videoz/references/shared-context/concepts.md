# Concepts

## Segment
- A numbered group of **clips** (`<n>-head`, `<n>-screen`, `<n>-audio`)
- Artifacts for that group live in `edit/<n>/`

## Clip
- Numbered raw video **clips** in `<src>` in the format `<n>-<clip-type>`
- The number on a **clip** is the **segment** it belongs to
- If **clips** are not numbered, stop and ask the user to number them

## Active Clip
- The main focus of a **beat**, the **clip** that is on screen before any other overlays or PIP

## Clip Types

### A-Roll

Used as the **active clip** for the majority of **beats**

- `screen`: A screen recording, usually paired with PIP
- `head`: A talking head camera shot
- `graphic`: A motion graphic used to illustrate a point (provided by the user or generated by you)
- `audio`: Audio only - typically recorded in step with the **A-Roll**

### B-Roll

Supplementary footage used as the **active clip** for cuts or visual interest

- `wide`: Wide shot that sets a scene/location
- `detail`: Close up shot (ex. Hands typing, an object, etc.)
- `reaction`: Shows a persons reaction to something, even if they aren't the speaker
- `cutaway`: Brief shot away from the main action, used to bridge edits
- `voiceover`: Audio only - recorded separately from the **A-Roll** footage

## Take
- One line in a series of repeated lines
- We are looking to keep the best **takes**
- Each **take** belongs to a **Beat**
- Each **take** may be built of multiple cuts the same clip (ex. if there is silence in the middle of a good take)

## Beat
- A set of **takes** that repeat the same words or meaning

## Scene
- A set of **Beats**
- Each **Scene** tells a story or serves a purpose in the video flow, using a group of **Beats**

## Clocks
- **Segment clock**
    - Time relative to a segments **audio reference clip**
    - `audio_source` in `ranges`
    - Used to sync clips
    - Renderer maps that clock onto `active_clip` using `edit/<n>/sync.json` (`audio_source` is already on that clock)
- **Edit clock**:
    - The time relative to the final edit output
    - Used to plan the video
- In `plan.html` 
    - Write times as `HH:MM:SS.ss` (hundredths of a second, always two fractional digits)
        - The **EDL** stores the same values as float seconds (`9.41`)
    - Write ranges as `E:<time>-<time>` for the **edit clock** and `S:<time>-<time>` for **segment clocks**

## Audio Reference Clip
- For a **segment** with multiple **clips**, this is the **clip** audio is sourced from and secondary **clips** are synced on
- In `ranges`, defined with the `audio_source` key
