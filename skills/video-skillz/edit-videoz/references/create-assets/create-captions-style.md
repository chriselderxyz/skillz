# Create New Captions Style
- Ask the user for a style name and description
- Map the description to style fields
  - case ("upper" | "lower" | "title" | "normal")
  - chars_per_line (int)
  - num_lines (int)
  - font_name (str)
  - font_size (px)
  - bold (bool)
  - italic (bool)
  - underline (bool)
  - strike_out (bool)
  - spacing (px between chars)
  - angle (degrees)
  - primary_color (HEX value)
  - outline_color (HEX value)
  - back_color (HEX value)
  - border_style (1 -> outline + shadow | 3 -> opaque background box)
  - outline (px)
  - shadow (px)
  - alignment (int - number pad position)
  - margin_v (px - best to be >= 90 to avoid cutoffs)
- Ask clarifying questions if required
- Save the result to `assets/caption-styles/<name>.json`
- Use the new style as the `caption_style` input variable
- Copy the JSON onto `edit/edl.json` as `caption_style` (a **segment** **EDL** may override individual keys)

# Verification Loop
- Create a caption preview using steps in `references/create-artifacts/create-caption-preview.md`
- Show the user `edit/caption-style/preview.png`, and `edit/caption-style/preview-9x16.png` when it exists
- Wait for feedback
- Adjust the style JSON and re-run the preview until they approve
