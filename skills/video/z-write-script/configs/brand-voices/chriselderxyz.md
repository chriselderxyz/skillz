# Grammar

## Word Elongation

### Context
- For emphasis.
- Use sparingly.

### Examples
- "wayyyy".
- "sooo".
- "neeed".
- "YEARSSS".
- "whhhole".
- "verrry".
- "toooo".
- "suuuuper".
- "realllly".
- "oooook".
- "nowwww".
- "alllright".

## ALL CAPS

### Context
- Used for emphasis and pivots.
- Applied to single words mid-sentence.

### Examples
- "BUT".
- "MUST".
- "ONLY".
- "REAL".
- "ACTUALLY".
- "NEEDED".
- "EVERYTHING".
- "IS".
- "ANY".
- "BEST".

## Staccato Puntuation

### Context
- Used to force word-by-word delivery.
- For emphasis on a point.
- Use sparingly.

### Examples
- "Stop. Putting. Everything. In. A Goroutine."
- "there are. no. shortcuts."
- "But. still. terrible."
- "keep, taking, every, next, step."

## Ellipsis

### Context
- Used to indicate a pause.

### Examples
- "Go Variables... Are Weirdly Complicated".
- "Is the code good... Nnnnnno. it's terrible."
- "Ok..."

## Contractions

### Context
- In general, prefer contractions over full words.
- Full words may be used sparingly for emphasis on important points.

### Examples
- "don't" not "do not".
    - Can use "do not" for emphasis.
- "I'm" not "I am".
- "we're" not "we are".
- "you'll" not "you will".

## Don't Use Em Dashes
- No em dashes.

# Phrasing

## Don't Sound Stuffy
- No fancy language.

### Bad Examples
- "And a quick word on".

## No Asides

### Context
- Avoid using asides, they are jarring and interrupt the script.
- Work the point into the script instead.

### Bad Examples
- "And this is the one everybody trips on, so let me be really clear about it".
    - Adds fluffy exposition around a topic instead of directly explaining or telling the viewer why they should care.

## Call to Actions
### Context
- Mid-roll CTAs ride inside the content.
- Do not do a hard break/cut to a CTA.

### Examples
- "And if you want to see more deep dives like this, theeenn... subscribe for more!"
- "There are also some more gotchas in composition that I'll cover in the next video... *like and subscribe* (whispered)".

## The Sign Off
The same every time.
- "And as always, keep breathing, keep building, and I'll see ya next time, peace out!"

# Structure

## One Line Per Breath

### Context
- Lines break where the voice pauses.
- End on commas rather than periods mid phrase.

### Examples
```md
So instead of Don't Repeat Yourself,
The BETTER Rule that I like to follow,
is Don't Repeat Yourself More Than 3 times".
```

## Transitions

### Context
- Used to transition between script sections/sub-sections or points within a section.
- Use sparingly, and vary transitions across the script.

### Examples
- "BUT!"
    - on its own line used to pivot into a counterpoint.
- "Annnnd, now you know when to use recursion!"
    - Elongated and for emphasis, with a quip referencing past content.
- "Alright, next up were covering <topic>".
- "Ok, now that you understand <topic>, we can talk about <topic>".

# Content and Meaning

## Do Not Use Corporate Language
- Videos should be loose and relaxed.
- No "marketing polish".

## Assert Flat, Soften With Humor

### Context
- Good for hooks (top-level or section level).

### Examples
```md
There is no such thing as Good Code,
there is definitely Bad code **lol**,
But Good code is a myth
```

## Anti-Dogma is the House Position

### Context
- Opinion pieces attacking a received best practice is interesting to viewers.
- Only do so if it fits the video.
    - Prevailing opinions must be refuted with a personal opinion backed by personal experience or external evidence.

### Examples
- DRY is bad advice.
- Good code is a myth.
- There are no bad languages.
- Tewrites are always wrong.
- There are no shortcuts.

## Rhetorical Questions

### Context
- State a rhetorical question, then directly it.
- Use sparingly.
- Only use if the question is actually something the viewer would be asking themselves based on the previous content.

### Examples
- "So why use it at all?"
- "So when should you use recursion?"

## Meta-Humour
### Context
- Humour about this video's format itself.
- Humour around cliche content in popular videos.

### Examples
- "And that concludes my TED talk."
- "don't forget to like and subscribe for more super solid opinions."
- "apparently it helps the channel, which is very new."
- "And subscribe I guess".
