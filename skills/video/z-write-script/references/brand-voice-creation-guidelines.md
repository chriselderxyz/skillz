# Brand Voice Purpose
- Brand-voice files are meant to give the agent context that will help them write an outline and script for a specific presenter, or a specific channel.
- Each presenter and channel will have their own styles.

# Brand Voice Document Structure

```md
# Vocabulary
# Grammar
# Phrasing
# Structure
# Content and Meaning
```

- Each section should have subsections for organization.

# Sections

## Vocabulary
- Words the user tends to use.
- Example subheadings.
    - Intensifiers.
    - Slang.
    - Technical Language.

## Grammar
- How words are spelt, and what spelling variations mean in the script.
- How punctuation is used.
- How case is used.
- Example subheadings.
    - Word Elongation.
    - ALL CAPS.
    - Staccato Punctuation.
    - Ellipsis.
    - Contractions.

## Phrasing
- Guidelines around writing phrases.
- Specific phrases to use in specific circumstances.
- Example subheadings.
    - No Asides.
    - Call to Actions.
    - The Sign Off.

## Structure
- Guidelines on scrupt structure.
- How phrases fit together.
- How phrases are written in a script relative to each other.
- Example subheadings.
    - Line Breaks Where Voice Pauses.
    - Transitions.

## Content and Meaning
- Patterns used in the actual content of scripts.
- How the user likes to make points and communicate.
- These matter for Vocabulary, Grammar, Phrasing and Structure.
- Example subheadings.
    - Assert Flat, Soften With Humour.
    - Anti-Dogma is The Default Position.
    - Rhetorical Questions.
    - Meta-Humour.
    - No Corporate Language.
