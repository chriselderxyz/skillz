# Source Group
- A numbered group of **sources** (`<n>-head`, `<n>-screen`, `<n>-audio`).
- Artifacts for that group live in `edit/<n>/`.

# Source
- Raw assets for the video in `<src>`.
- Assets in a **source group** follow the format `<n>-<source-type>`, where `n` is the group number.

# Audio Source
- For a **source group** with multiple **sources**, this is the **source** the audio comes from. The other **sources** are synced to it.
- `audio_source` on each **source group** in `edit/edit.json`.

# Layer
- One picture in a **line**.
- `layers` on each **line** is the render stack, back to front.

# Full Graphic
- An `animation` or `image` **layer** with no **layer** under it.
- It is the content, used to support the audio.

# Overlay Graphic
- An `animation` or `image` **layer** over another **layer**.

# Source Types

## A-Roll
- Primary footage for the edit.
- Types.
    - `screen`: A screen recording, usually paired with PIP.
    - `head`: A talking head camera shot.
    - `animation`: A designed visual that moves (provided by the user or generated by you).
    - `image`: A still image (provided by the user or generated by you).
    - `browser`: A browser recording of a webpage, generated by you.
    - `audio`: Audio only - typically recorded in step with the **A-Roll**.

## B-Roll
- Supplementary footage used on a **layer** for cuts or visual interest.
- B-Roll is may or may not be part of a **source group**.
- Types.
    - `wide`: Wide shot that sets a scene/location.
    - `detail`: Close up shot (ex. Hands typing, an object, etc.).
    - `reaction`: Shows a persons reaction to something, even if they aren't the speaker.
    - `cutaway`: Brief shot away from the main action, used to bridge edits.
    - `clip`: Footage from another creator.

# Cut
- A single section within a **source**.
- The smallest unit of video composition planning.
- Each **cut** belongs to a **take**.
- A take may have one or more cuts.

# Take
- One attempt at a **line**.
- We are looking to keep the best **takes**.
- Each **take** belongs to a **Line**.
- Each **take** may be built of multiple cuts the same source (ex. if there is silence in the middle of a good take).

# Line
- A set of **takes** that repeat the same words or meaning.

# Scene
- A set of **Lines**.
- Each **Scene** tells a story or serves a purpose in the video flow, using a group of **Lines**.

# Clocks
- **Audio Source clock**.
    - Time relative to that **source group**'s **audio source**.
    - Used to sync sources.
- **Edit clock**.
    - The time relative to the final edit output.
    - Used to plan the video.
- In `edit/edit.json`.
    - Write times as `HH:MM:SS.ss` (hundredths of a second, always two fractional digits).
    - `edit_start` / `edit_end` are on the **edit clock**, `audio_source_start` / `audio_source_end` are on the **audio source clock**.
