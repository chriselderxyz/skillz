# Definitions
- **Concept** -> One thumbnail idea and its low quality image.
- **Variation** -> One fully built thumbnail, in its own top-level layer of `thumbnail.af`.
- **Asset** -> An image placed in a **variation**.
- **Thumbnail Style** -> The `thumbnail_style` config, which sets the background and the colors on it.
- **Font Style** -> The `font_style` config, which sets the fonts and the text outline width.
- **Thumbnail Guidelines** -> The `thumbnail_guidelines` config, which sets the rules, style, layout, and existing **assets** of every thumbnail.
