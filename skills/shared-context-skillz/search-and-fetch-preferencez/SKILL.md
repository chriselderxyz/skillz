# Search and Fetch Tool Preferences

## Technical Documentation
- Only search for the subset of docs you need for the current task
- Tools to Try (in order listed):
    - Context 7 MCP
    - Exa MCP
    - Agents native search/fetch tools
    - GitMCP to load the repository if fetching docs failed or results are poor

## Semantic Search
- Applies to all searching other than searching technical documentation
- Tools to Try (in order listed):
    - Exa MCP
    - Agents native search/fetch tools
