name: z-run-cross-check
description: Used to cross-check information provided by another agent.
---

# Phase 1: Catalogue

- Consider the information and sources you have been provided, including the likelyhood of the sources veracity.

# Phase 2: Search and Verify

- Search for separate independent sources that can be used to verify the information.
- Do not use any sources provided to you, we are cross-checking those.
- 2-3 sources in agreement is ideal.

# Phase 3: Respond

- Respond with a description of how confident you are the that the provided information is correct.
- Include a confidence percentage from 0-100.
- If you are not confident.
    - Explain why.
    - Explain what part of the information may be incorrect.
    - Provide possible corrections to the information.
    - Include the sources that disagree.
